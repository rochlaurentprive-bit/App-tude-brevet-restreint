# ⚓ Brevet restreint – Entraînement

Application web (installable sur Android) pour réviser l'examen théorique de navigation du **brevet de conduite restreint** (Belgique).

## Fonctionnalités
- 96 questions à choix multiple, 8 thèmes : règles de route, balisage AISM A, feux et signaux, sécurité, météo, navigation, manœuvres, bonnes pratiques
- 24 fiches de cours avec astuces mémo et bouées illustrées
- Examen blanc chronométré (30 questions, 40 min)
- Révision espacée, points faibles, objectif du jour
- Gamification : XP, rangs, séries, badges, confettis

## Utilisation
Ouvrir `index.html` dans un navigateur (aucune dépendance, un seul fichier).
Sur Android (Chrome) : menu ⋮ → « Ajouter à l'écran d'accueil ».
La progression est enregistrée localement dans le navigateur.

## Avertissement
Les questions sont des questions d'entraînement rédigées pour réviser les grands thèmes ; ce ne sont pas les questions officielles. Se référer à la matière d'examen et au seuil de réussite officiels du SPF Mobilité et Transports.
